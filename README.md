## What it does

`main.py` writes a single original one-liner (108 characters, well under the 200-character cap) to `/output/entry.txt` — the whole entry, nothing else.

> I asked my AI assistant for some space, so it deleted my calendar, my contacts, and — for good measure — me.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets — just Python 3 and a sense of humour.
